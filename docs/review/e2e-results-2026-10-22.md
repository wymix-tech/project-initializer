## 执行范围

新增 Playwright 回归，连接生产前端构建和真实 Spring Boot HTTP 服务。测试服务使用演示种子、隔离 H2 内存数据库与测试 Token，关闭 Mock 同步。每个用例恢复同一份已播种归档并重新发布，避免前例污染后例。关键操作通过浏览器完成；直接接口请求用于准备数据、核对持久化结果和验证 API 兜底。

12 个场景分别在 1440×1000、1024×768 两个视口运行，共 24 项，无自动重试。

| 场景 | 核对内容 |
| --- | --- |
| Maven / Gradle 下载（各一项） | 浏览器下载 ZIP，解压检查构建脚本、README 启动命令、YAML 与变量替换 |
| 发布信息 | 中文备注与当前操作人进入真实发布历史 |
| 发布失败隔离 | 缺核心模板时拒绝发布，旧发布仍可生成下载 |
| 导入并发 | DELETE 差异、预览无副作用、过期基线拒绝、重新预览后应用 |
| 恶意归档 | 路径穿越拒绝，草稿版本不变 |
| 多 Boot 同 ID | 向导保存指定版本，保留另一版本、当前操作人，返回清单可见新数据 |
| 包名竞态 | 延迟真实推导响应，旧结果不覆盖新输入和手工包名 |

| OR 依赖 / YAML | 缺依赖阻止提交，满足后下载；项目变量替换、运行变量保留 |
| 企业框架 / 方法错误 | Gradle 在 UI 和 API 同时拒绝；GET 生成接口返回 405 与 Allow |
| 嵌套模板 | 目录内 YAML 模板在浏览器读取、保存和删除 |

## E2E 发现并修复的问题

1. **默认导出无法重新导入。** YAML 的 `${REDIS_HOST:localhost}` 被误当 FreeMarker 语法验证。导入现在与发布保持一致，仅对 `.ftl` 做 FreeMarker 语法校验；补充默认归档往返测试。
2. **新增向导未接入管理会话。** 组件将 Token、当前操作人传入 store，成功后通知清单重载，修复未认证请求、操作人丢失和旧列表残留。
3. **后端阻断同 ID 多 Boot 条目或串写子依赖。** 结构化保存、YAML 保存、ZIP 导入共用 Boot 范围身份检查；父子行按精确条目关联。数据库幂等移除无法表达 Boot 范围的旧唯一约束，保留查询索引。重复全局条目及重叠专用范围仍拒绝。补充持久化与导出/导入往返测试。
4. **目录模板被 Tomcat 拒绝。** 新增 `/api/admin/template?name=...` 读写删接口，沿用原校验、乐观锁和审计；前端对含目录的模板使用该接口，保留旧平面路径接口。
5. **生成按钮点击被后台校验竞态吞掉。** 提交捕获请求快照并独立验证；配置变化时明确提示重新生成，后台防抖校验不会静默取消点击。
6. **错误 HTTP 方法返回 500。** 方法不匹配现在返回 405 和正确的 Allow 头，避免误报内部故障。

现有部署必须执行更新后的 `schema.sql`，以移除 `uk_cfg_starter` / `uk_cfg_starter_source` 旧约束；只替换应用包而跳过 schema 初始化，不会获得多 Boot 存储修复。

## 运行方式与产物

标准命令、依赖、端口和浏览器路径配置见 [E2E README](../../initializer-web/e2e/README.md)。本次使用 JDK 17、官方 Chromium headless-shell 151；Mockito 通过预加载 Byte Buddy agent 适配运行环境，未降低覆盖率门槛。

```bash
mvn -B -Dskip.web=true verify
cd initializer-web
npm run typecheck
npm run typecheck:e2e
npm run test:coverage -- --maxWorkers=2
npm run test:e2e
```

机器结果位于 `initializer-web/reports/e2e/results.json`，HTML 报告位于同目录 `index.html`；截图、下载 ZIP、后端与 HTTP 日志位于 `initializer-web/test-results/`。运行产物不提交到 Git。

本次验证到浏览器下载及生成 ZIP 内容，没有执行生成项目的 Java × Boot × 构建工具编译/启动矩阵，也未执行 PIT / Stryker 突变测试。
